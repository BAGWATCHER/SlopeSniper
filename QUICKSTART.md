# Quick Start: SlopeSniper in 5 Minutes

The absolute fastest way to start trading Solana tokens with AI.

---

## Prerequisites

- Moltbot already installed ([Get it here](https://molt.bot))
- A messaging app connected (WhatsApp, Telegram, or Discord)

---

## Step 1: Install (1 minute)

```bash
curl -fsSL https://raw.githubusercontent.com/BAGWATCHER/SlopeSniper/main/skills/install.sh | bash
```

---

## Step 2: Create Wallet (2 minutes)

```bash
slopesniper setup
```

**SAVE YOUR PRIVATE KEY** when shown - it's only displayed once!

---

## Step 3: Fund Wallet (1 minute)

1. Copy your wallet address from setup
2. Send 0.1-0.5 SOL from your main wallet
3. Wait 30 seconds

Check balance:
```bash
slopesniper status
```

---

## Step 4: Trade! (1 minute)

Message your Moltbot:

```
You: check my status
You: buy $5 of BONK
You: what's trending?
```
